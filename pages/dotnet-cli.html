.NET CLI

.NET CLI (Command-Line Interface) to międzyplatformowy zestaw narzędzi wiersza polecenia, który służy do tworzenia, budowania, uruchamiania i publikowania aplikacji .NET bez konieczności używania rozbudowanego środowiska IDE (np. Visual Studio). Jest instalowany automatycznie razem z zestawem .NET SDK.

Tworzenie podstawowej aplikacji .NET CLI

dotnet --version
dotnet --list-sdks
dotnet new list
dotnet new console -n MojaAplikacja
cd MojaAplikacja
dotnet restore
dotnet build
dotnet run
dotnet clean
